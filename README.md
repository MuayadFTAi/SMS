# Student Management System

A simple command-line Student Management System developed in C++.

## About the Project

This project is a console-based application designed to manage basic student records.

It was developed to practice fundamental C++ programming concepts and apply them in a practical project.

## Features

- Add a new student
- Search for a student
- Update student information
- Delete a student record
- Display student records

## Technologies

- C++
- Command Line Interface (CLI)

## Concepts Used

The project uses fundamental C++ concepts, including:

- Structures
- Arrays
- Strings
- Loops
- Conditional statements
- Functions
- Basic record management
